# WORKFLOW

## Project
Student Registration Form

## Round 1
I asked AI to create a simple student registration form using HTML, CSS, and JavaScript. The generated form had basic input fields and a submit button. It worked but had limited validation and a simple design.

## Round 2
I improved my prompt by asking for a responsive design, validation for name, email, phone number, and password, clear error messages, and clean, accessible code. The result was much better and more user-friendly.

## Comparison
Round 2 produced a better form because the prompt was more detailed. The code was cleaner, the design was improved, and the validation made the form more reliable.

## AI Mistake I Fixed
The AI did not properly validate the phone number. I reviewed the code and corrected the validation so only valid phone numbers are accepted.

## Three Rules I Learned
1. Write clear and specific prompts.
2. Always review AI-generated code.
3. Test the code before submitting.

## Conclusion
This assignment taught me that better prompts lead to better results. Human review is important to ensure the final code is correct and meets all requirements.
